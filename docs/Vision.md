# FRIDAY — Vision

## Mission

Build the world's best open-source desktop AI agent that can use Windows like a human.

FRIDAY is **not** "an AI assistant" and **not** "a Jarvis clone." It is a genuine
**Desktop Intelligence Platform** — an operating system's AI layer, not another
chatbot project.

## One Job

> **Understand. Plan. Execute. Verify. Learn.**

Everything else is a module. The core supplies the loop; plugins supply the
capabilities.

## What FRIDAY is

- A durable, event-driven runtime that routes work between swappable capabilities.
- A memory system that remembers across sessions the way people do.
- A permission layer that keeps autonomous action safe on a real machine.
- A platform: voice, vision, browser, terminal, coding, and Windows automation
  are all replaceable plugins.

## What FRIDAY is not

- Not a single monolithic LLM prompt.
- Not locked to one model, one vendor, or one programming language.
- Not allowed to act dangerously without explicit approval (see `Security.md`).
- Not a research demo — it is built to run on a real desktop every day.

## Target environment

Primary: Windows 10/11, local-first, with optional cloud model fallbacks.
Reference dev machine: RTX 3060 6GB, Ryzen 7, 32GB RAM, 1TB SSD.

## Non-goals (for now)

- Cloud-only hosting.
- Mobile clients.
- Replacing the OS; FRIDAY operates *within* Windows, it does not take it over.
